# Cinderreach Menu Art & Look-Target Pipeline

Generated by headless Blender 4.0.2 + "bpy_helpers.py" (`Cycles`, AgX color management) from scripted 3D geometry & KayKit Dungeon/Adventurer meshes, imported into Ordner `MenuArt` unter `sandbox/Assets/Resources` as single-sprite UI assets (`MenuArtImporter.ImportAsSprites`).

> AI concept sheets (Ordner `refs`) are **look targets only** and never ship inside Ordner `sandbox/Assets`.

## Reproducible Blender Scripts

- `docs/menu-art/build_icons.py` — equipment & item sprites (`256x256` RGBA):
  - Fenwalker weapons: `ShortSword`, `HeavyAxe`, `Dagger`
  - Lanternbearer weapons: `Lantern`, `EmberCenser`
  - Armor & Helms: `ClothTunic`, `LeatherVest`, `Breastplate`, `Hood`, `Helm`, `Circlet`
  - Currency: `GoldCoin`
- `docs/menu-art/build_icons_extra.py` (`--final`) — `ShortBow` (covers HuntingBow / Worn Short Bow),
  `HoodedLantern`, `HealingPotion`. Round history: bow limbs re-swept across screen-X so the arc reads
  at 25/12; potion body rebuilt as solid red brew (emissive shell blew out to cream).
- `docs/menu-art/build_props.py` — 3 gothic dungeon/town props (`256x256` RGBA):
  `TorchSconce`, `LootChest`, `BloodBanner` (EEVEE 64sp, transparent).
- `docs/menu-art/build_menu_pack.py` — Portraits, skill icons, badges & startup key art:
  - Portraits (`256x256` RGBA): `PortraitFenwalker`, `PortraitLanternbearer`, `PortraitVendor`
  - Skills (`256x256` RGBA): `SkillFireball`, `SkillArrow`, `SkillCleave`, `SkillLanternBolt`, `SkillWisps`, `SkillSearingHalo`, `SkillVeilStep`
  - Badges (`256x256` RGBA): `CrestCinderreach`, `WaypointSigil`, `StashChestIcon`, `SettingsCog`
  - Startup Key Art (`1024x576` RGB): `StartupBackdrop`

## Regenerate & Reimport

```bash
blender -b --factory-startup --python-exit-code 1 -P docs/menu-art/build_icons.py
blender -b --factory-startup --python-exit-code 1 -P docs/menu-art/build_props.py
blender -b --factory-startup --python-exit-code 1 -P docs/menu-art/build_menu_pack.py
bash scripts/run-unity-build.sh MenuArtImporter.ImportAsSprites "[MenuArt] ImportAsSprites done" 600
python3 scripts/check-meta.py
```
